# Paralyx

Collateralized Turkish lira credit lines on Stellar. Post XLM collateral to a Blend v2 pool, borrow USDC, cash out lira through a SEP-6 anchor, repay in lira. Testnet build for the Rise In x Stellar Pro Hackathon, Scale track, Istanbul, 19 to 20 September 2026.
